還差一步設定

網站還沒有連上資料庫。請依 README 建立 Supabase 專案，並把網址與金鑰填進 config.js：

window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "你的 anon key"
};

存檔後重新整理這個頁面。

管理員
行事曆 文書題庫 選手 題庫管理
日一二三四五六

    文書題庫

    選一份題目，每一題可以繳兩份檔案：一份 DOCX、一份 PDF（兩份都繳或只繳一份都可以）。繳交後會蓋上已繳章，檔案送到後台，不評分。

      選手

      所有選手的繳交都在這裡。點「查看」可以進到某位選手，看他每一題的檔案並開啟。

      選手

      題庫管理

      決定選手看得到哪些題目。新增、修改都不會動到已繳交的檔案。題目一旦有人繳交，就只能隱藏、不能刪除；隱藏後選手看不到，但「選手」頁仍看得到。

      新增年度

      每個年度會建立正式賽與模擬賽各一份，每份預設 6 題。已隱藏的年度會重新顯示。

      新增自製題目

      自製題目都是模擬題，會顯示在該年度的正式賽、模擬賽旁邊。

      整理舊年度

      沒有人繳交的會刪除，已有繳交的會改成隱藏，檔案不會被動到。先預覽，再確認。
