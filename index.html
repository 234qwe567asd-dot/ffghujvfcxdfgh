還差一步設定

網站還沒有連上資料庫。請依 README 建立 Supabase 專案，並把網址與金鑰填進 config.js：

window.APP_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "你的 anon key"
};

存檔後重新整理這個頁面。
